(async) WCanvas(optopt) → {Promise}

Description:

  • 取得可用之node-canvas(官方npm套件canvas)，回傳其匯出(createCanvas、loadImage、registerFont等canvas之全部匯出，原樣)

    npm 12預設不執行canvas之安裝腳本(prebuild-install)，故安裝後canvas缺少build/Release/canvas.node而無法載入。 本函數於首次調用時，經ensureBins依bin/manifest.json自官方GitHub版本標籤(Automattic/node-canvas)下載預建檔(tar.gz)，以SHA-256與大小逐檔校驗(canvas.node與44個dll，共45檔)後存於快取， 再把這45檔複製到canvas套件之build/Release(已存在且雜湊相符者略過，否則寫入同資料夾之暫存檔並驗證後以更名覆蓋，不讀到半檔，多個行程同時首次調用皆可成功)，最後動態載入canvas並回傳其匯出。 之後自快取取得(亦校驗)，安裝時不下載。預建檔須與canvas之JS同版，故本套件釘選canvas確切版本，已安裝之canvas版本與清單所載不同時reject E_VERSION。

    本版只支援win32-x64。其他平台若canvas自身之build/Release/canvas.node已存在(例如使用端自行編譯)則直接載入，否則reject E_PLATFORM。

    離線與內網之用法(環境變數W_BIN_CACHE、W_BIN_MIRROR、W_BIN_OFFLINE)見README〈外部執行檔〉，部署前可預先調用WCanvas.ensureBins()取得。 Windows下目標檔若被其他行程載入(例如換版時舊版canvas.node仍在執行中)無法覆蓋，reject E_BIN_LOCKED，須先結束載入舊版之行程。

    canvas: Automattic/node-canvas(官方預建檔取自其GitHub版本標籤之資產)

Example
import fs from 'fs'
import WCanvas from 'w-canvas'

async function test() {

    //WCanvas, 首次調用時下載並校驗官方預建檔，複製到canvas套件後載入
    let { createCanvas, loadImage, registerFont } = await WCanvas() // eslint-disable-line no-unused-vars

    //畫一個藍色矩形與中英文字
    let canvas = createCanvas(240, 80)
    let ctx = canvas.getContext('2d')
    ctx.fillStyle = '#fff'
    ctx.fillRect(0, 0, 240, 80)
    ctx.fillStyle = '#1976d2'
    ctx.fillRect(10, 10, 60, 60)
    ctx.fillStyle = '#000'
    ctx.font = '24px sans-serif'
    ctx.fillText('測試 canvas', 80, 48)

    //輸出PNG
    let buf = canvas.toBuffer('image/png')
    fs.writeFileSync('./test-canvas.png', buf)
    console.log('size', buf.length > 0)
    // size true

    //loadImage
    let img = await loadImage(buf)
    console.log('wh', img.width, img.height)
    // wh 240 80

    fs.unlinkSync('./test-canvas.png')
}
test()
    .catch((err) => {
        console.log('catch', err)
    })

ensureBins(optopt) → {Promise}

Description:

  • 取得本套件之外部執行檔: 檔案組canvas(官方預建檔之canvas.node與其44個dll, 共45檔)

    首次使用時下載(或自鏡像取得)官方預建檔(tar.gz)，解出後逐檔以bin/manifest.json之SHA-256與大小校驗，整組原子放入快取，之後自快取取得(亦校驗，一檔不符即整組重取)，安裝時不下載 規格: 外部執行檔之存放下載校驗與離線(制式規格)§6、M6; 實作為wsemi之fsEnsureBins, 本套件不另寫下載、快取、鏡像、校驗與解壓 快取預設於本套件根目錄之bin-cache/(與當前工作路徑無關), 環境變數: W_BIN_CACHE、W_BIN_MIRROR、W_BIN_OFFLINE, 見README〈外部執行檔〉

    本函數只負責取得至快取，不把檔案複製到canvas套件之build/Release，也不檢查作業系統(連網機器可為離線部署預備鏡像)，載入canvas請用WCanvas

(async) placeBins(files, dirTarget, optopt) → {Promise}

Description:

  • 把檔案組之各檔放置到canvas套件之資料夾(內部使用)

    每檔: 目標已存在且大小與SHA-256相符者略過; 否則複製為同資料夾之暫存檔並驗證其內容，再以更名覆蓋目標(原子，不讀到半檔)。 更名被拒(目標被其他程序載入，Windows之DLL鎖)時，若目標此時已相符(他程序剛放妥)視為成功，否則reject E_BIN_LOCKED。 canvas.node最後放置(中途失敗時不留下有canvas.node而缺dll之狀態)。
